Local contract review with Ollama

Gavin Ferns built a self-hosted AI tool to support contract review when commercially sensitive documents need to be processed locally.

Area
Applied AI
Workflow
Contract review
Model runtime
Self-hosted Ollama

The problem

Reviewing commercially sensitive documents.

A contract question can take a reviewer from the main agreement to a schedule and then to an amendment. The documents may contain commercially sensitive material, and the team may need to review them within its own environment.

What Gavin built

A contract review tool with a local model.

Gavin built the tool around a self-hosted Ollama installation so the model could process contract text in the local environment. That lets a team explore AI-assisted contract review without sending the text to a cloud model for processing.

The tool is intended to support the first pass. The reviewer checks the original wording and any amendments before relying on a finding.

Ollama documentation on local processing

Illustrative example

Checking a notice requirement.

This fictional example illustrates the review task. A project team wants to know when a notice is due and where it must be sent.

The first pass

Look for the notice clause, the event that starts the clock and the schedule that names the recipient.

The reviewer’s check

Read those provisions in the signed documents, check whether an amendment changes them and record the wording that supports the answer.
