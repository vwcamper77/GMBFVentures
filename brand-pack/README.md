# GMBF Ventures brand pack

## Logos and icons

- Use the main logo on light backgrounds and the reverse logo on dark backgrounds.
- The GF monogram with the green italic F is the current website favicon. The standalone Open G is included in SVG, PNG and ICO for separate use.
- Use the social card for link previews where a 1200 × 630 image is required.

## Email

Open `email/signature.html` in a browser. Copy the rendered signature into your mail app’s signature editor. For Zoho, use Settings → Signatures. If your editor drops the image when you paste, insert `email/email-logo.png` and set its display width to 255 px. `email/signature.txt` is the text-only version.
