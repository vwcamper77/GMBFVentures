# GMBF Ventures

Responsive static website for [gmbfventures.co.uk](https://gmbfventures.co.uk).

## Preview locally

```bash
npx serve .
```

The site is plain HTML, CSS and JavaScript and has no build step.

## Deploy to Vercel

Import the GitHub repository in Vercel and select **Other** as the framework
preset. Leave the build command empty and use `.` as the output directory.

After deployment, add both `gmbfventures.co.uk` and
`www.gmbfventures.co.uk` under **Project Settings → Domains**. Vercel will
show the exact DNS records to enter at the domain registrar.
